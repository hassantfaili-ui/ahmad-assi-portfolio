The lot is 14 metres wide, which is too narrow for a double loaded corridor to be efficient and too wide to give up on. The plan that worked puts the corridor against the party wall and opens every unit to either the street or the courtyard, with the stair and services stacked at the lane.

Ninety units, all rental, none of them below 42 square metres. Holding that floor area against the pro forma was the longest running argument on the project and the only one that mattered to the eventual tenants.

It did not get built. The financing moved and the site is still a parking lot. I include it because the permit set is some of the most careful work I have done, and because unbuilt is not the same as unresolved.
